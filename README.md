# Kitap — библиотека с интерактивными компонентами

Готовая статическая версия для GitHub Pages. Для публикации npm не нужен.

## Публикация архива
1. Распакуйте архив. Загрузите всё его содержимое в репозиторий, заменив предыдущие версии файлов.
2. index.html должен находиться в корне. Сохраните папку assets и её содержимое.
3. GitHub → Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. После успешного развёртывания откройте сайт. При старом оформлении нажмите Ctrl+F5.

В исходном репозитории Sites публикуется папка dist; ZIP подготовлен с готовыми файлами в корне для GitHub Pages.

## Добавленные компоненты
- Anime.js 4.2.2: последовательное появление главного блока, книг и декоративной орбиты.
- Motion 12.23.24: переходы карточек, наклон обложек, подсказки поиска, окна перевода, прогресс чтения.
- Kokonut UI: Action Search Bar и Particle Button, адаптированы под библиотеку.
- 21st.dev: Shine Border от Magic UI / Dillion Verma. Использован исходный MIT-компонент, представленный в каталоге 21st.dev; это не отдельный JS SDK.
- React используется только для небольших интерактивных компонентов, остальная логика сайта сохранена.

Анимации и компоненты собраны локально в assets/ui-enhancements.js. При недоступности этого файла остаются базовые функции библиотеки. Системная настройка prefers-reduced-motion отключает декоративное движение.

Поиск: Ctrl+K / Cmd+K, стрелки для выбора, Enter — открыть книгу, Escape — закрыть подсказки.

## Редактирование компонентов (не нужно для обычной публикации)
Исходники: src/. Зависимости: package.json и package-lock.json.
Установите Node.js, затем выполните npm ci и npm run build:ui.
Если PowerShell блокирует npm.ps1, используйте npm.cmd ci и npm.cmd run build:ui.
Сборка обновляет assets/ui-enhancements.js в распакованном ZIP, либо dist/assets/ui-enhancements.js в исходном репозитории Sites.

## Данные и ограничения демо
Книги, задания, сохранённые книги, прогресс и результаты остаются в localStorage текущего браузера. На том же адресе старые данные сохраняются. На другом домене автоматически не переносятся. Общего сервера и авторизации администратора пока нет.
Импорт PDF/EPUB/DOCX и внешний перевод требуют интернета; сервис перевода может ограничивать запросы. PDF без текстового слоя не распознаётся.

## Проверка
Проверены в DOM-тесте: поиск, клавиатура, сохранение, навигация читалки, подсчёт теста и открытие административной формы. Декоративные эффекты учитывают prefers-reduced-motion. Визуальная проверка в настоящем браузере в этой среде недоступна.
