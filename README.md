# Kitap — демоверсия библиотеки

Статический сайт: HTML, CSS и JavaScript. Node.js и npm для запуска не нужны.

## Публикация на GitHub Pages
1. Создайте репозиторий kitap (Public для бесплатного GitHub Pages).
2. Распакуйте ZIP и загрузите index.html, style.css и app.js в корень репозитория через Add file → Upload files.
3. Нажмите Commit changes.
4. Откройте Settings → Pages.
5. В Build and deployment выберите Source: Deploy from a branch.
6. Выберите ветку main и папку / (root), нажмите Save.
7. Дождитесь публикации; адрес появится в Settings → Pages.

Обычно адрес: https://ВАШ-ЛОГИН.github.io/kitap/
Не загружайте ZIP вместо распакованных файлов. index.html должен лежать в корне.

## Особенности демо
- Книги, прогресс, задания и результаты сохраняются в localStorage текущего браузера.
- На новом домене данные, созданные на старом сайте, автоматически не появятся.
- Управление — демонстрационная панель без авторизации. Изменения видны только в том браузере, где они сделаны.
- Для общей библиотеки и защищённой панели администратора нужен backend.
- Перевод использует учебный словарь и внешний API MyMemory, который зависит от интернета и ограничений сервиса.
- Импорт PDF/EPUB/DOCX загружает библиотеки из CDN; PDF без текстового слоя не распознаётся.
- Шрифты загружаются из Google Fonts, при недоступности используются системные.
