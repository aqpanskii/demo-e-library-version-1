# Third-party components and animation libraries

Kokonut UI Action Search Bar and Particle Button — MIT.
https://kokonutui.com/docs/navigation/action-search-bar
https://kokonutui.com/r/action-search-bar.json
https://kokonutui.com/r/particle-button.json
Adapted for Kitap: Russian labels, actual library search, native CSS, keyboard navigation and reduced motion.

Shine Border by Magic UI / Dillion Verma — MIT; discovered through the 21st.dev catalogue:
https://21st.dev/@dillionverma/components/shine-border
Original open-source registry: https://magicui.design/r/shine-border.json
21st.dev is a catalogue, not an additional JavaScript runtime. This site uses the actual listed Shine Border component, adapted to local CSS.

Anime.js: entrance choreography and hero orbit animation.
Motion: React search dropdown and particles; card, page and popover transitions.
All code required for these effects is bundled locally into assets/ui-enhancements.js.
